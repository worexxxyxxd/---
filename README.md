# СТИМУЛ-С — сайт каменной отделки

Статический сайт на пять страниц:
- `index.html` — главная и преимущества
- `stone.html` — дагестанский камень и направления работ
- `projects.html` — визуальное портфолио
- `gallery.html` — фотогалерея объектов и работ
- `contacts.html` — телефон и форма заявки

Откройте `index.html` в браузере или загрузите папку `stone-site` на статический хостинг. Зависимостей и сборки нет.

Форма заявки проверяет имя и телефон и собирает сообщение для WhatsApp номера +7 925 809-09-99. Посетитель подтверждает отправку в WhatsApp. Для автоматической передачи без участия посетителя подключите серверную форму или CRM.
